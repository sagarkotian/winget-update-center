# Privacy Policy for Winget Update Center

Effective date: September 7, 2026

Winget Update Center is published by Sagar Kotian. This policy explains how the Winget Update Center extension for Microsoft PowerToys Command Palette handles information.

## Information processed by the extension

Winget Update Center runs Windows Package Manager (`winget`) on the user's computer to display installed applications and available updates. To provide this functionality, the extension temporarily processes information returned by Winget, including application names, package identifiers, installed versions, available versions, package sources, and command results.

This information remains on the user's device. Winget Update Center does not send installed-application information, command results, or other personal information to the publisher.

## Information collected by the publisher

Winget Update Center does not require an account and does not collect analytics, telemetry, advertising identifiers, precise location, contacts, credentials, or payment information. The publisher does not operate a server that receives information from the extension.

## Storage and retention

The Command Palette extension does not create a persistent inventory, history database, or cloud backup. Inventory and update information is held only as needed to display the current Command Palette session. Windows, Microsoft PowerToys, Winget, configured package sources, and individual installers may maintain their own logs, caches, or records independently of Winget Update Center.

## Network access and third parties

Winget may contact package sources configured on the user's computer to retrieve package metadata and installers. Those services and installers are provided by Microsoft or third-party package publishers and are governed by their respective privacy policies and terms. Winget Update Center does not control their data practices.

## Package installation

Winget Update Center starts an update only after the user selects an individual update or the Update all command. Package installation is performed by Winget and the selected package's installer. Winget or an installer may request additional permission, including administrator approval, when required.

## Children's privacy

Winget Update Center is a general-purpose software-management utility. It does not knowingly collect personal information from children.

## User choices

Users can choose whether to check for or install updates. Because Winget Update Center does not send personal information to the publisher or maintain a persistent user database, the publisher has no stored personal information to access, export, or delete. Users can remove the extension through Windows application settings at any time.

## Changes to this policy

This policy may be updated if the extension's data-handling practices change. Any updated policy will include a revised effective date.

## Contact

For privacy questions about Winget Update Center, contact Sagar Kotian using the support contact information shown on the product's Microsoft Store listing.
